# EP 17 — production notes (`/init` → CLAUDE.md)

**Topic:** `/init` auto-generates a CLAUDE.md. Docs: https://code.claude.com/docs/en/memory
(*"Run `/init` to generate a starting CLAUDE.md automatically. Claude analyzes your codebase and creates a file
with build commands, test instructions, and project conventions it discovers."*)

**Angle:** demonstrated on a *docs/markdown* project (the move-abroad plan), reinforcing the series' "not just for
code" thread — shown as an **observation**, not asserted as a documented guarantee (the docs frame `/init` around a
codebase, so the captions deliberately avoid the words "works on any project").

## ⛔ SENSITIVE-DATA GATE — do NOT record against the real repo

The story repo `Stig-Johnny/gran-canaria-plan` is the operator's **real** family-relocation + Invotek income plan.
`/init` scans the **whole** project and streams its work to the terminal — it lists the directory (exposing sensitive
**filenames**) and reads files (README.md and `INVOTEK_BRAIN.md` alone leak DOB, org.nr, MVA, phone, business/forwarding
addresses, income status, named third parties, and an annotated index of every sensitive file). A recording of `/init`
on the real repo **publishes all of that**. There is no safe way to run the advertised command against the real repo.

### Record against a sanitized stand-in instead
**DECISION (locked 2026-06-12): sanitized stand-in.** Build a throwaway folder that mimics the shape (a static site
+ a few markdown notes) using **only** non-sensitive, logistics-only material. Turnkey prep at render-time:

```bash
# in a scratch dir, NOT under series/ — build the demo repo the recording points at
SRC=~/src/gran-canaria-plan          # a fresh clone of the real repo
DST=~/runthedocs/scratch/cc-ep17-demo
rm -rf "$DST"; mkdir -p "$DST"
# allowlist only — copy nothing else, and NO README/BRAIN
for f in kalender.html research.html gran-canaria-prepurchase-checklist.md obsidian-oppsett.md styles.css; do
  cp "$SRC/$f" "$DST/"
done
# add a 2-line neutral README so /init has a title but zero figures/addresses/names:
printf '# Move plan\n\nA small static site + markdown notes for planning a family move.\n' > "$DST/README.md"
cd "$DST" && git init -q && git add -A && git commit -qm "sanitized demo project for ep17"
# THEN: open Claude Code here, run /init, and review the generated CLAUDE.md frame-by-frame before publishing.
```
`skole.html` and `praktisk.html` are **intentionally omitted** (may name the child / school / health). Verify each
copied file is clean before recording; if any names a person/figure, drop it. Allowed real files (clean-checked):
`kalender.html`, `research.html`, `gran-canaria-prepurchase-checklist.md`, `obsidian-oppsett.md`, `styles.css`.
**Exclude entirely:** `README.md` (original), `skole.html`, `praktisk.html`,
`INVOTEK_BRAIN.md`, `okonomi.html`, `juss.html`, `accountant-brief-*`, `aarsplan-inntekt.md`, `fase0..4-detaljert.md`,
`inntekt-remote-strategi.md`, `mal-liste-*.md`, `skatteradgiver-kandidater.md`, `tilbud-*.md`, `content-the-rig.md`,
`compliant-linkedin-amplification.*`, `dokumenter/`. Give the stand-in **no README** (or a 2-line neutral one with zero
figures/addresses/names). Note: even some "safe" files (`skole.html`, `praktisk.html`) may name the child / school /
health — **review them before including, and review the generated CLAUDE.md frame-by-frame** for any name, figure,
address, or third party before publishing.
