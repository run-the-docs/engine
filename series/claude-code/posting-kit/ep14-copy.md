## LinkedIn (upload the 4:5 natively — no link in the body)

Watching Claude grep around for the file you meant?

Skip it. Type `@` and the filename, and Claude drops the whole file into the conversation. No searching, no waiting for it to read around.

`@` a folder instead and you get its file listing. Chain a few in one message: `@file1.js and @file2.js`.
