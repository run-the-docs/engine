Forgot what you actually shipped this week?

Claude Code isn't only an interactive session. `claude -p` runs a single prompt, prints the answer, and exits.

It reads stdin, so you can pipe anything into it:

`git log --oneline -20 | claude -p "summarize these commits"`

Instant standup. Drop the same trick into any script or your CI.
