## Distribution model — UPDATED 2026-06-09
**Post as Stig (personal profile), not the Invotek company page.** Personal reach beats the company page (his own data + the algorithm's human-comment bias). The brand lives in the **handle + bio**, never stamped salesy in the post body. Bio/headline: *"developer education at Run the Docs · founder, Invotek (AI/software consultancy)."*

- **Run the Docs = the loud, vendor-neutral content brand** (YouTube/TikTok); **Invotek = silent owner** ("a project by Invotek" in bios/footers only).

## How to post (the rules that drive reach)
1. **Upload the video natively** to each platform — never post a YouTube/external link in a LinkedIn body (it suppresses reach).
2. **Hook is line 1.** The copy is written so the first line works alone in the feed (assume the rest is hidden behind "…more").
3. **First comment:** post it yourself within ~1 minute — it holds the YouTube link, the **newsletter CTA**, and a soft Invotek line. Keep the post body link-free.
4. **Guard the first 60–90 min:** reply to every comment with a real follow-up question — early engagement velocity is what the algorithm rewards.
5. **3–5 hashtags**, at the very end, niche + broad.
