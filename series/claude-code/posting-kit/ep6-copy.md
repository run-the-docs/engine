## LinkedIn  (upload `ep6-linkedin-4x5.mp4` natively — no link in the post body)
Claude just rewrote a file and made it worse, and now I'm scrolling up trying to remember what it looked like before.

Turns out I never have to do that. Claude Code checkpoints my code before every edit.

Every prompt I send is a checkpoint. I press Esc twice on an empty prompt (or run /rewind), pick the moment to go back to, and choose what to restore: the code, the conversation, or both.

One honest caveat I learned the hard way: it tracks Claude's file edits, not files changed by bash commands, and not manual edits I make outside the session. So I still keep Git for permanent history. I treat checkpoints as local undo and Git as the source of truth.
