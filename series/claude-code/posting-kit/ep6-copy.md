## LinkedIn  (upload `ep6-linkedin-4x5.mp4` natively — no link in the post body)
Claude just rewrote a file and made it worse. Now you're scrolling up trying to remember what it looked like before.

You don't have to. Claude Code checkpoints your code before every edit.

Every prompt you send is a checkpoint. Press Esc twice on an empty prompt (or run /rewind), pick the moment to go back to, and choose what to restore: the code, the conversation, or both.

One honest caveat: it tracks Claude's file edits, not files changed by bash commands (and not manual edits made outside the session) — so keep Git for permanent history. Think of checkpoints as local undo, Git as the source of truth.

> Pro-tip: "Restore conversation" rewinds the chat but keeps your current code — and it drops the original prompt back into the input box so you can re-send or edit it. Great when you want to re-ask without throwing away edits you liked. The rewind menu also has Summarize options: a targeted /compact that compresses one side of a long session to free up context, without touching files on disk (your original messages stay in the transcript). Bonus: checkpoints persist across sessions, so you can rewind even in a resumed conversation.
