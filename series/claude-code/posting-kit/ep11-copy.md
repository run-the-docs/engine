## LinkedIn (upload natively, NO link in body)

I used to babysit my context window in Claude Code — quitting sessions early because I was scared of "running out."

Turns out I had it backwards. A full window does not end your session. Claude Code auto-compacts as you approach the limit and keeps going.

Three commands I now lean on every day:

- /context — a live breakdown of what is actually filling your window, by category, with tips to trim it. Start here.
- /compact — replaces the conversation with a structured summary so you can keep working. CLAUDE.md, your memory, and MCP tools reload automatically. Add a focus, like /compact focus on the auth bug, and it keeps exactly what you choose.
- /clear — when you switch to unrelated work, wipe the slate so old context stops crowding out the files you need next.

Read the window, compact with a focus, clear between tasks. That is the whole game.

How do you decide when to /compact versus /clear?
