## LinkedIn  (upload `ep5-linkedin-4x5.mp4` natively — no link in the post body)

Your best prompts shouldn't live in one person's head.

Most teams retype the same instructions every day.

Claude Code fixes that with slash commands.

Type / for built-ins:
- /review — review the current diff
- /resume — pick up where you left off
- /clear — reset the context

Then save your own. Drop a markdown file in .claude/commands/, add $ARGUMENTS for inputs, commit it.

Now your whole team runs the same prompt, the same way — straight from git. 30 seconds in the demo.

Watch the 30s terminal demo, then steal the pattern. What's the one prompt your team retypes every single day?
