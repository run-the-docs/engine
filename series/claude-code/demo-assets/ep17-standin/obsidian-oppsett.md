# Obsidian-oppsett

Kort notat om hvordan denne vault-en er organisert, så alt er lett å finne igjen senere.

## Mapper

- `00-inbox/` — raske notater som ikke er sortert ennå
- `10-plan/` — tidslinje, sjekklister og avgjørelser
- `20-research/` — områdenotater og lenker (offentlig info)
- `30-documents/` — referanser til skanninger (selve filene ligger utenfor vaulten)
- `90-archive/` — ferdige eller forkastede notater

## Konvensjoner

- Én idé per notat; lenk heller enn å kopiere.
- Bruk tags som `#move`, `#housing`, `#visa`, `#school`.
- Datoer skrives relativt (M0, M+1, …) så lenge planen ikke er låst.
- Ingen sensitive personopplysninger i selve notatene — kun referanser.

## Daglig bruk

1. Skriv alt nytt i `00-inbox/` først.
2. Rydd inbox én gang i uka og flytt til riktig mappe.
3. Hold `10-plan/` som én kilde til sannhet for hva som skjer når.
